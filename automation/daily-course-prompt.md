# Codex 每日课程自动化任务

每天中午 12:00 运行。目标是新增且只新增一节课程，并发布到 GitHub，Vercel 会自动部署。

## 执行步骤

1. 读取 `prompts/course-system.md` 和 `data/courses.json`。
2. 找到当前最大 `day`，下一课编号为最大值加 1。
3. 按 system prompt 生成一个新的课程 JSON 对象。不要重复已有中文模型名、英文模型名或高度相似主题。
4. 将新对象追加到 `data/courses.json` 数组末尾。
5. 运行 `npm run validate`。
6. 如果校验失败，恢复本次对 `data/courses.json` 的修改，再重新生成；最多重试 3 次。
7. 只有校验成功且确实只新增一节课时，提交并推送到 GitHub。
8. 如果远端已经有同一天课程，先拉取远端最新内容，重新判断下一课编号，避免重复发布。

## 成功标准

- `data/courses.json` 的 Day 编号连续。
- 本次提交只新增一节课程，且不改写旧课程。
- 提交信息使用：`Add day N mental model`，其中 N 是新增 Day 编号。
- 推送成功后不需要手动部署，Vercel 会自动发布。

## 失败处理

- 生成失败、校验失败、网络失败或 Git 推送失败时，不要破坏旧数据。
- 如果无法确认远端状态，不要发布重复课程。
- 在自动化结果里说明失败原因和需要人工处理的下一步。
